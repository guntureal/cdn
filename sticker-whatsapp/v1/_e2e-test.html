Stiker WhatsApp

Ubah foto sendiri menjadi stiker WhatsApp — background terhapus otomatis, ukuran pas 512×512, siap disimpan ke WhatsApp.

Seret foto untuk mengatur posisi. Background dihapus mengikuti bentuk orang di foto.

Simpan stiker ke WhatsApp

  1. 1File stiker-whatsapp.webp sudah diunduh ke perangkat kamu.
  2. 2Buka WhatsApp, masuk ke chat mana saja.
  3. 3Ketuk ikon emoji → tab Stiker → ikon Buat.
  4. 4Pilih file stiker-whatsapp.webp, lalu kirim sebagai stiker.
  5. 5Tekan lama stiker yang terkirim → Tambahkan ke Favorit agar tersimpan permanen.

WhatsApp tidak menyediakan akses bagi situs web untuk menyimpan stiker secara langsung, jadi file stiker perlu ditambahkan lewat aplikasi WhatsApp dengan langkah di atas.
